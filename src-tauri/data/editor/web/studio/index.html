常见问题

.litematic 到底是什么文件？
Litematica 模组的投影文件格式，记录一座建筑里每个位置该放什么方块。它不是存档，加载它不会改变你的世界，更像一张贴在空中的施工图。
不装 Litematica 模组能看吗？
能。浏览器里直接打开，不用装模组也不用开游戏。等你要在游戏里照着搭建时，才需要 Litematica。
文件会上传到服务器吗？
不会。解析全部在你的浏览器本机完成，文件不会离开你的电脑。只有你主动点「保存到账号」时才会上传。
支持哪些格式？能互转吗？
导入导出都支持 .litematic 与 .schem，导出时自己选，跟导入的是哪种无关 —— 所以它顺带也是一个格式转换工具。材质清单另可导出 .csv 或 .json。
能一次替换很多方块吗？
能，两种方式：整份投影按材质全局替换，把某一种方块全换掉；或者先框选出一块范围，只替换这块里的。改坏了 Ctrl+Z 退回去。
需要登录吗？要钱吗？
浏览和编辑不用登录；导出投影需要登录，登录后会接着把刚才那次导出做完。不要钱：建筑库、投影编辑、壁纸站、Blender 四个板块全部免费开放，不设付费门槛。
能打开多大的投影？手机能用吗？
本地打开上限 50 MB，存到账号建议 25 MB 以内。手机浏览器能打开和查看，但大文件受手机内存限制。
跟 Litematica 模组是什么关系？
这是网页工具，Litematica 是游戏内的模组，两者配合用：在这里改好、导出文件，再用 Litematica 载入游戏，照着投影搭建。
